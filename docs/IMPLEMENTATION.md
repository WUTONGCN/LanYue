# 览阅桌面版实施约定

目标：保留固定上游版本 kkFileView 的全部预览路径；Mac 和 Windows 可解压运行；无需全局 Java、LibreOffice、Docker；格式能力以样本验收记录为准。

采用轻量静态桌面界面 + Electron 主进程 + 独立沙箱预览页面 + 本机 kkFileView 子进程。完整组件随包分发，按需启动。用户原文件只读；缓存和运行状态写入应用数据目录。Windows 可在 EXE 旁放置 portable-data 目录使用便携数据模式；macOS 的只读卷和 App Translocation 不影响默认用户数据模式。

体积策略：分平台、分架构打包，只携带运行时；移除调试符号、开发工具和构建文件；不裁剪格式转换库、字体、模型解析器。后续优化必须通过格式样本回归。

验收库存：空状态、打开对话框、多文件拖入、前后切换、工具展开与收起、键盘快捷键、加载/失败/重试、预览返回、缓存清理、原文件保护、引擎退出、离线网络约束。核心格式样本：TXT、中文文件名、PDF、DOCX、XLSX、PPTX、ZIP、DWG/DXF、STL/OBJ、STEP/IGES、IFC、OFD、音视频。异常路径：文件移走、损坏文件、并发切换、缺失组件、中文及特殊字符路径。每种平台单独记录，不以源码路由覆盖替代实机验收。

签名和公证属于正式发行工作；开发包不能宣称已签名或保证消除 Gatekeeper / SmartScreen 提示。免安装不自动设置系统默认文件关联。

极简界面：不显示品牌区、侧栏、文件库、最近记录、分类、搜索、标签栏、格式宣传、设置页和状态栏。不持久化最近文件。三维、PDF、CAD 的辅助工具默认收起，按需展开。
